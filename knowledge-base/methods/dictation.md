# 单词默写与覆盖

先确认本次单元、真实词库和数量，查看最近两轮与覆盖记录。词库不可读取就索取清单，不凭印象从几个熟词里循环抽取。

抽词优先级：上次/前一天确认错词复查，其余以该范围未默过的词和低覆盖词为主；有额度才加入间隔复习词。范围已全覆盖时明确改为间隔复习。具体数量由家长/孩子选择，不把另一个家庭的每天数量硬编码进来。

私有覆盖表至少记录单元、词、日期、出题次数、真实错词和复查结果；公开仓库只放空结构。词汇 app 默认只读，不写回其数据库。

默认流程：中文提示 -> 孩子说“好了” -> 对应英文答案核对 -> 只报错题号。目的为核对时可以给答案；错号、拼写或转写含糊先确认。不能把“好了”、看过答案或订正全对记为独立掌握。

新闻与口语从真实词汇记录挑少量词自然复现，形成“认词、拼写、听懂、会用”的不同证据，不用打卡次数替代全部能力。
