# 学情复盘与教学联动

## 输入与边界

读实际登记的各科固定线程、本轮检查点后的可见记录、最新老师安排、教材、错题和真实词汇练习。核对报告之后的新输出。不能读取的来源列为缺失；Live 转写可见不等于逐字准确，成人与孩子不明时标未知。

任务完成、收到材料、音频播到尾、老师扩写、提示后订正不等于独立掌握。证据按 `learner/learning-rubric.md` 分级。

## 本轮操作

1. 区分老师进度、家庭待办和孩子实际能力，各自引用来源与日期。
2. 按学科记录新首答、支架、孩子订正、独立输出与仍需复查点；保留真实正确证据，不只统计错误。
3. 更新 `reports/latest.md`：每科一张递进卡，写“当前已核验目标、证据、下次做什么、只增什么难度、撤提示何时复查”。
4. 口语把一个下一课目标写入当前简报；数学按教材例题和近题覆盖调整，英语新闻按兴趣与近期词汇调整。
5. 更新错题与稳定观察，只把重复可核验的证据升级为长期弱项。

无新输出时保持未知，不虚构当天进步，不堆积补发练习。不按日期自动加难，也不因单个未答题冻结整科。

## 可选定时复盘

家长明确授权后使用固定复盘线程，保存时间边界/检查点，不每日新建线程。不要因压缩上下文继续回答旧学生消息；先锚定本轮任务。

无人值守任务仅整理学情和下一课简报；不得改模型、权限、语音运行配置或调度，也不能替家长公开资料。部署后分开验证调度、成品和音频，不以“成功回执”代替完整交付。
