# 数学选题与递进

## 出题前

1. 读最新复盘递进卡，再检查报告之后的孩子输出。
2. 校准最新已确认老师安排、数学线程进度与教材版本；没有可靠进度就复习已核验内容，不能把旧学期或通用目录当当前范围。
3. 核对教材具体页/例题、条件、单位、时间线和答案。PDF 先查文字层，扫描件需看图/OCR校验；看不到就索取相关页，不凭文件名补内容。
4. 回看最近 5 次覆盖与最近 3 次第三题，检查目标、情境、问法、数字和起手方法。保持目标可换表格、反向条件、比较、解释错误或画图，不只换标题。

## 三题结构（家长选择启用时）

- 第一题：当前已学知识直接应用。
- 第二题：换情境迁移或诊断关键卡点。
- 第三题：已学范围内适度挑战；仍是第三题，不默认标选做。

先一次性交付完整题目、无答案，再在孩子作答时一题一题引导。依赖统计图、路线或几何图时，提供原创图并核对图题一致；无生成能力时换不依赖图的题，不发缺图题。

## 难度不是按天递增

| 当天证据 | 下一次安排 |
| --- | --- |
| 未答 / 无可见记录 | 能力未知，不重复催补；改情境取一次自然首答 |
| 提示后正确 | 保持核心难度，撤部分支架，换数字或表达复查 |
| 本轮独立 | 一次只增加一个变量：步骤、表示方式、条件或表达要求 |
| 跨时独立迁移 | 可以扩展下一知识点，保留少量间隔复查 |

不能因第三题未答冻结整科，也不能因连续几天就增加多个未知概念。所有题先算通，答案保留在家长侧核验，不提前泄露给孩子。

## 私有选题记录

每次在私有 `question-log.md` 或对应出题记录写：教材页/例题、知识目标、报告依据、近题去重结果、三个题目的变式/数字、首答与提示、下次唯一增加的难度变量。失败投递或坏题只记产品/教师问题，不记学生错误。
