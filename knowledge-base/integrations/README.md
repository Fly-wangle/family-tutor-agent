## 来源用法

- 老师通知 / 学习计划：优先校准本班进度、作业范围和时间，区分在校已完成与孩子待做，不据待办状态推掌握。
- 词汇 app：只读真实词库、近期练习、错词与覆盖；缺数据就注明，不能凭记忆填记录。
- 教材 / 音频：核对版本与对应正文；原件留私有 materials，需检索时取局部文字并视觉核验。
- 学生线程 / Live 转写：只处理授权且实际可见的内容，明确时间边界和说话人不确定项。

公开模板不绑定某个 app、数据库或线程；运行接口与访问权限需各家庭单独配置，不擅自写入外部数据库。口语近期目标见 `oral-session-brief.md`。
