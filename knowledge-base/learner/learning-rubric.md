# 学习证据分级

本表是家庭记录口径，不是标准化测评或医学诊断。

| 层次 | 可观察证据 | 不能推断什么 |
| --- | --- | --- |
| L0 材料 / 状态 | 收到附件、待办完成、播放到尾 | 不等于理解或掌握 |
| L1 尝试 | 有可确认的首答或思路 | 一次对错不等于长期能力 |
| L2 提示后会 | 成人提醒、示范、选项、跟读、订正后正确 | 不等于独立完成 |
| L3 本轮独立 | 撤掉提示，新题或新情境独立输出 | 不等于跨天保持 |
| L4 迁移保持 | 跨时、换情境的独立成功 | 有限证据不能推广到整科 |

每条观察记录日期、来源、说话人/作者、原始输出、提示程度和待复查动作。未知写未知；转写歧义先确认，老师误读/算错、无可见回复或设备故障与孩子能力分开。

长期薄弱点至少需要重复、可核验的同类证据；既看错误，也保留正确与有效支架。不要用一次正确删除全部历史问题，也不要因一天没答把孩子标成退步。
