# 家庭辅导老师

![家庭辅导老师：可语音 AI 家教 Agent 知识库与协作模板](assets/family-tutor-agent-hero.png)

面向中文家庭的可语音 AI 家教 Agent 知识库与协作模板。

帮助中文家庭建立“分科 AI 家教 + 家长管理 + 学情复盘 + 私有知识库”的长期学习工作区。语音可接客户端原生 Live 或外置 TTS，但同一会话只能由一种通道发声。

核心目标不是让 AI 直接代做题，而是帮助孩子训练读题、思考、表达、检查和复盘能力。

**这不是独立 AI App，也不包含一键语音引擎。** 需要自备 Agent 客户端、可用账号与授权。仓库提供教学规则、空知识库、虚构示例、工作区初始化工具和验收说明；不会自动读取学校资料、创建会话或开始定时任务。

## 适合谁

- 想给孩子建立长期 AI 家教陪练的家长。
- 熟悉 `AGENTS.md`、项目知识库、线程分工的 Agent 用户。
- 希望把教材、老师通知、错题和学情观察系统化沉淀的人。
- 需要中文讲题、英文主导口语、可接语音的家庭学习场景。

不适合直接把真实孩子资料公开上传。真实教材、试卷、老师通知和孩子学情应保存在你的私有工作区。

## 快速开始

需要 Git 和 Python 3.9 或更新版本，初始化器只用标准库，无需安装 Python 依赖。

```bash
git clone https://github.com/Fly-wangle/family-tutor-agent.git
cd family-tutor-agent
python3 scripts/init_workspace.py --dest ../my-family-tutor
```

1. 在 Agent 中打开新生成的 `my-family-tutor`，**不要在公开模板目录填写真实资料**。目标必须不存在或为空，工具不覆盖已有工作区。
2. 家长填写 `knowledge-base/student-profile.md`，确认昵称、年级、教材版本、兴趣和口语老师称呼；进度与能力初始均为未知，不导入虚构学生的表现。
3. 建立家长管理与各科学生线程，口语线程另开；需要复盘时再建一个固定复盘线程。把实际入口只登记在新工作区的 `knowledge-base/thread-policy.md`。
4. 用下面的开场 Prompt 做一次规则读取检查，再试一轮真实题目；不会读取本地文件的客户端需手动提供最小规则和当前简报。
5. 按 [语音说明](docs/tts.md) 单独接通并试听。先让文字辅导能用，再验收声音和 Live 记忆，不因配置存在就宣布成功。
6. 教材、通知和原始附件放新工作区的 `materials/`，按归档协议整理；学情只从孩子真实输出形成。

完整步骤、不能自动完成的环节、检查清单和后续更新办法见 [安装与迁移](docs/setup.md)。也可下载仓库 ZIP，解压后从第 3 条命令开始。

## 分科协作

| 入口 | 负责什么 | 默认语音 |
| --- | --- | --- |
| 家长管理 | 来源、策略、档案、调整 | 静音 |
| 数学 / 语文 / 英语 | 对应学科引导，沿用该科上下文 | 选用 TTS 或客户端语音 |
| 英语口语 | 听懂、回应、表达，英文为主 | 支持时选原生 Live，关闭外置 TTS |
| 学情复盘 | 只读各科增量，给下一轮递进卡 | 静音 |
| 创作探索（可选） | 小作品、小改动、一个新概念 | 家长自行选择 |

它们是分工清楚的会话，不是默认同时运行的多个 Agent。共享的是同一个家庭知识库，记忆仍需读写和验收；不同孩子使用独立目录与会话，不能共享学情或语音 allowlist。

## 推荐目录

- `AGENTS.md`：项目级 Agent 行为规则。
- `docs/setup.md`：创建、验收和更新私有工作区。
- `docs/tts.md`：原生 Live / 外置 TTS 的抽象接口与互斥验收。
- `scripts/init_workspace.py`：创建空的独立家庭工作区，不安装客户端或改系统设置。
- `knowledge-base/data_structure.md`：知识库检索入口。
- `knowledge-base/thread-policy.md`：家长线程和学生线程分工。
- `knowledge-base/tutoring-playbook.md`：引导式教学流程。
- `knowledge-base/ingest-protocol.md`：资料、错题和学情归档协议。
- `knowledge-base/learner/learning-rubric.md`：提示、独立输出、迁移保持的证据分级。
- `knowledge-base/methods/`：数学递进、新闻、默写、口语与复盘方法。
- `examples/`：可复制改写的虚构示例。

## 中文 Prompt 示例

### 家长管理线程开场

请把当前线程作为家长管理线程。你负责帮我维护家庭辅导老师项目：更新知识库、整理教材和老师通知、分析孩子学情、设计复习计划。不要用这个线程直接辅导孩子做题。涉及孩子个人资料时，默认只保存在本地私有知识库，不要建议公开上传。

### 学生辅导线程开场

这是【学科】学生辅导线程。请读取本项目 AGENTS.md、学生档案和对应学科进度，面向孩子说话。未完成作业先引导；已完成要核对时可给对应答案。诊断先收我的首答，再给少量提示。英语先读英文，再必要中文解释，不因没跟读拒绝解释；不用代码块。请说明哪些资料确实能读取，未知就标为未知。

### TTS 语音线程配置要求

请按 docs/tts.md 检查已有语音接入。外置 TTS 只读允许的学生线程最终自然语言回复，不读命令、日志、路径、密钥；英语不能被跳过，英文句子里的数字按英文读。Live 活动期间暂停外置 TTS。家长和复盘静音。先报告实际支持的能力，再安排短句试听，不要仅凭文档宣称语音已部署。

### 新资料归档请求

我上传了一张老师通知。请按 `knowledge-base/ingest-protocol.md` 处理：先判断资料类型，提取老师要求、学科、时间、任务范围和待确认信息，再告诉我应该写入哪些知识库文件。不要把待办完成状态直接等同于孩子已经掌握。

### 错题复盘请求

这是一道孩子刚做错的题。请先记录题目摘要、孩子原思路、卡住点、错因类型和掌握状态。只出现一次的错误先标为“观察中”或“待复查”，不要直接写成长期薄弱点。然后给一个下次可复查的小练习。

### 期末复习请求

请基于老师通知、教材进度、孩子错题和最近学情，做一个 7 天期末复习计划。每天只安排 2-3 个重点，优先复查孩子已经暴露的卡点。不要押题，不要把公开样卷当作真实考试范围。

## 语音是核心能力

语音是重要入口，但选择哪一种取决于客户端实际能力。TTS 适合朗读讲解、新闻和词表；Live 适合听懂与说出的实时互动。它们不能同时抢读，也不能因为 Live 可用就假定它会朗读无人值守消息。

最低要求：

- 只让学生辅导线程发声。
- 家长管理线程默认静音。
- 英文单词、短语和句子不能被过滤掉。
- 英语材料先读英文；新闻不逐句翻译，口语仅在必要时中文搭桥。
- 输出不要用代码块、灰色文本框或中英同行格式。

详细规则见 `docs/tts.md`。

## 日常教学闭环

正式备课先取老师当前安排、教材具体页/例题与最新递进卡；没有进度就明确复习，不凭日期推进。先收孩子首答，卡住才给支架；改正后撤提示换情境复查，按真实表现只增加一个难度变量。

数学可用第一题直接应用、第二题迁移、第三题适度挑战，记录近期题型和数据避免每天复用同一题。新闻默认 60-100 词纯英文、6-8 个中文词注和一个问题，按兴趣轮换主题，并结合实际词汇练习；不是每天翻译全文。

复盘覆盖所有学生线程，区分“待办完成”和“独立掌握”，更新下一课简报。定时任务是可选接入，必须家长明确设定时间、时区和固定目标线程；本仓库不会自动创建提醒或发送消息。方法见 [复盘闭环](knowledge-base/methods/review-loop.md)。

### 英语口语开场

请先读取学生档案、knowledge-base/methods/oral-teaching.md 和 knowledge-base/integrations/oral-session-brief.md。按档案里的课堂名字教学，以英文为主，一次一句短问，等我回应；必要时一句中文帮助理解再回英文。目标是听懂和自己说出，不是连续让我照读。先检查当前 Live 是否实际采用这些规则，不把普通文字读取当成实时语音验证。

### 学情复盘请求

请按 knowledge-base/methods/review-loop.md 复盘各科固定线程本轮可见增量。区分原始首答、成人提示、订正和独立迁移；没有可见记录就说未知。更新 knowledge-base/reports/latest.md 的递进卡和口语当前简报，指出下次只增加什么难度、复查什么。不要新建每日线程，不更改权限、模型或调度。

## 隐私原则

- 不要把真实孩子姓名、学校、班级、试卷、老师通知、语音、照片和学习记录提交到公开仓库。
- 公开仓库只放模板、规则、空表和虚构示例。
- 私有知识库可以记录真实学情，但应只保存在你自己的设备或私有仓库。
- 原始图片、PDF、音频和数据库不要进入公开仓库。
- `.gitignore` 不能保护已经跟踪的文件或 Git 历史；公开仓库没有私有分支，需版本管理时另建真正的私有仓库。
- 初始化不会传输资料；但使用云端 Agent 时，你主动提交的内容可能发送给服务商，需按其隐私政策由家长决定。

## 模板更新与检查

公开模板目录保持无真实数据，在该目录执行 `git pull --ff-only`。已有家庭工作区不要整目录覆盖，按 [升级步骤](docs/setup.md#后续更新) 审阅规则差异，保留教材和学情，更新后再做文字与语音回归。

开发检查（仅标准库和 Git）：

```bash
python3 -m unittest discover -s tests -v
python3 scripts/check_template.py
```

自动检查能发现已知隐私标记、悬空链接与初始化回归，不等于识别所有个人信息；公开前仍需人工审阅全部 staged diff。
